# Third-party notices

## oneko / xneko cat sprites

The cursor-following cat uses the public-domain `neko` bitmaps embedded by
[winebarrel/Neco](https://github.com/winebarrel/Neco). The original cat was drawn by
Juan Gotoh for neko DA, converted to X11 bitmaps by Masayuki Koba for xneko, and
carried forward in oneko by Tatsuya Kato. The exported PNG frames in
`public/neko-sprites/` preserve those bitmaps without generative alteration.

The browser state machine in `app/cursor-neko.tsx` is a TypeScript adaptation of
Neco's CC0 chase and idle-state logic.
