# Contributing to Neko

Thanks for leaving a paw print. Keep changes small enough to inspect and strange enough to belong here.

## Before opening a pull request

1. Create a branch from `main`.
2. Run `npm install` and `npm run dev`.
3. Check the desktop at wide and mobile widths.
4. Run `npm run lint` and `npm run build`.
5. Confirm no API keys, `.dev.vars`, `.env` files, private URLs, or personal data appear in the diff.

## Design rules

- Preserve the classic Macintosh illusion: hard pixel edges, compact typography, monochrome chrome, and a little teal dither.
- New windows must be draggable, closable, keyboard-reachable, and usable on mobile.
- Neko should be odd and warm, never noisy for its own sake.
- Random alerts must remain sparse. A desktop pet should feel alive, not behave like adware.
- Prefer original or clearly licensed assets and record their provenance in `THIRD_PARTY_NOTICES.md`.

## Commit messages

Short, present-tense messages fit best:

```text
Add modem archive window
Slow hungry alert timer
Repair Neko sleep animation
```

## Lore contributions

Secret Notes are written by Neko in first person. Give each memory concrete sensory detail, an imperfect recollection, and a reason it matters now. Avoid encyclopedia prose and exposition dumps. A useful test: it should sound like someone found the file, not like someone wrote a wiki page.
